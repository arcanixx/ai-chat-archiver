I'm learning Rust and struggling with ownership and borrowing. Can you explain with examples?

Let me explain Rust's ownership system with concrete examples:

Ownership Rules

  1. Each value has exactly one owner
  2. When the owner goes out of scope, the value is dropped
  3. References allow borrowing without taking ownership
fn main() {
    // Ownership example
    let s1 = String::from("hello");
    let s2 = s1;  // s1 is MOVED to s2
    // println!("{s1}"); // ERROR: s1 no longer valid

    // Borrowing with references
    let s3 = String::from("world");
    let len = calculate_length(&s3);  // &s3 borrows, doesn't own
    println!("'{s3}' has length {len}");  // s3 still valid

    // Mutable references
    let mut s4 = String::from("hello");
    change(&mut s4);
}

fn calculate_length(s: &String) -> usize {
    s.len()  // s is a reference, not owner
}

fn change(s: &mut String) {
    s.push_str(", world");  // can mutate through mutable ref
}

// Lifetime annotations
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}

I should cover the three main concepts: ownership transfer with move semantics, borrowing with shared & mutable references, and lifetime parameters. The user needs to understand that ownership is compile-time checked.

What about smart pointers and Box<T> vs Rc<T>?

4:02 PM

Smart pointers are crucial for Rust's memory safety. Here's a comparison:

PointerOwnershipThread-safeUse Case
Box<T>SingleYesHeap allocation, recursive types
Rc<T>Shared (ref count)NoSingle-threaded shared ownership
Arc<T>Shared (atomic ref count)YesMulti-threaded shared ownership
Cell<T>Single with interior mutabilityNoCopy types, runtime mutation
 
use std::rc::Rc;
use std::cell::RefCell;

// Rc for shared ownership
let shared = Rc::new(42);
let a = Rc::clone(&shared);
let b = Rc::clone(&shared);
println!("Reference count: {}", Rc::strong_count(&shared));

// RefCell for interior mutability
let data = RefCell::new(vec![1, 2, 3]);
data.borrow_mut().push(4);
println!("Data: {:?}", data.borrow());

// Box for heap allocation
let heap_val: Box = Box::new(100);
println!("Heap value: {}", heap_val);

I should emphasize that Rc is for single-threaded scenarios only (no Send/Sync), while Arc uses atomic operations for thread safety. RefCell enforces borrowing rules at runtime rather than compile time.
