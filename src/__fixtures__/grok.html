How do I optimize my ML training pipeline for better GPU utilization?

1:00 PM

Here are key strategies for GPU optimization in ML pipelines:

Data Loading

  • Use DataLoader with num_workers > 0
  • Prefetch with prefetch_factor=2
  • Use pin_memory=True for faster GPU transfer
from torch.utils.data import DataLoader

train_loader = DataLoader(
    dataset,
    batch_size=128,
    num_workers=8,
    prefetch_factor=2,
    pin_memory=True,
    persistent_workers=True
)

Mixed Precision

from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
for data in train_loader:
    optimizer.zero_grad()
    with autocast():
        output = model(data)
        loss = criterion(output, targets)

    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()

Gradient Accumulation

accumulation_steps = 4
for i, data in enumerate(train_loader):
    output = model(data)
    loss = criterion(output, targets) / accumulation_steps
    loss.backward()

    if (i + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
